# Rips4u demo

This is a clickable prototype of Rips4u. It takes no payments, and its packs, cards, and films don't exist.

Every visit starts a fresh demo with 22,900 Rips, 12 cards in the vault, and 4 sealed packs to open. Reloading the page puts the demo back to the start.

The site is one static page, `index.html`, served by GitHub Pages.
